## 📖 Tentang Project

**SIMKAT (Sistem Informasi Manajemen Kegiatan RT)** adalah aplikasi berbasis mobile yang dirancang untuk mempermudah pengurus RT dalam mengelola kegiatan warga serta menyampaikan informasi secara terpusat dan real-time.

Project ini dikembangkan sebagai bagian dari **mata kuliah Mobile Programming 2**.
